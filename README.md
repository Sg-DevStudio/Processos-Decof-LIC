# Processos - Decof_LIC

Repositório privado para organizar e versionar processos e arquivos de trabalho da Decof/LIC.

## Organização

- Cada processo deve permanecer em sua própria pasta.
- Novos arquivos devem ser adicionados à pasta do processo correspondente.
- Não armazenar senhas, tokens, chaves ou outras credenciais no repositório.

## Uso

O repositório serve como cópia de trabalho versionada e como fonte de consulta autorizada no Codex e no ChatGPT.

> Atenção: os documentos podem conter informações funcionais ou pessoais. O repositório deve permanecer privado e com acesso restrito.
